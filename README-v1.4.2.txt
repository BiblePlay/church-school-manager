교회학교 출석 · 달란트 v1.4.2 RECOVERY

이번 버전의 목적은 UI 복구/동결입니다.
- 상단 거대한 색상 블록 제거, 흰 배경 + 검정 라인 + 노랑 포인트
- 학생: 목록 -> 상세 -> 정보수정 흐름 통일
- 학생 정보수정 안에서 학년/미지정, 사진, 연락처, 보호자, 기타정보 편집
- 학생 명단 제외 + 완전 삭제를 정보수정 화면 하단에 배치
- 교사: 목록 -> 약식 상세 -> 정보수정 흐름 통일
- 교사 상세에서 닫기/뒤로 시 교사 명부 유지
- 교사 역할/직함, 생일, 연락처, 비고를 실제 편집 필드와 연결
- 교사 완전 삭제는 정보수정 화면 하단에 배치
- 달란트 리셋 버튼 유지
- 새 설치 시 가짜 샘플 학생/교사를 자동 생성하지 않음
- 기존 브라우저 저장 데이터는 STORAGE KEY를 유지하므로 그대로 이어짐

주의: 테스트 전에 기존 v1.4.1의 데이터가 중요하면 전체 백업 파일을 먼저 내보내십시오.
