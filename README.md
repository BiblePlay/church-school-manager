# v1.5.3.26-datapack-export-fix

기준 버전: `v1.5.3.25-final-filter-clean`

## 이번 수정 범위

데이터팩 내보내기 한 가지 오류만 수정했습니다.

- 임원·양육교사용 데이터팩 / 청년교사용 데이터팩은 다른 기기로 전달하는 JSON 파일이므로 `자료 폴더 지정`을 강제로 요구하지 않습니다.
- 데이터팩 내보내기 시 즉시 JSON 파일을 다운로드합니다.
- 동시에 앱 내부 `자료 보관함`에도 사본을 남겨 다시 찾을 수 있습니다.
- 받은 기기에서는 기존 `데이터팩 가져오기`로 같은 JSON 파일을 불러옵니다.
- 출석 기록 JSON/TXT, 전체 백업의 지정 자료 폴더 저장 동작은 변경하지 않았습니다.
- 학생/교사/출석/달란트/학년/팀/분석/Excel/데이터팩 내용 및 가져오기 병합 로직은 변경하지 않았습니다.

서비스워커 캐시: `church-school-v1.5.3.26-datapack-export-fix`
