# 교회학교 출석 · 달란트 PWA v1.5.3.21-final-release

기준 버전: `v1.5.3.20-final-complete`

이번 버전은 기존 안정 기능을 재작성하지 않고, 임원·양육교사가 **전체 학생 구성을 한눈에 파악할 수 있는 학생 분석 기능**과 그 분석에 필요한 비교정보 입력·필터·데이터 이동만 최소 연결한 최종 배포본입니다.

## 1. 기록 화면 — 부서 현황 + 학생 분석

임원·양육교사용 기록 화면 상단에 두 버튼을 나란히 둡니다.

- `부서 현황`: 기존 출석·운영 현황 유지
- `학생 분석`: 새 도넛 분석 화면

학생 분석은 기본 `전체`에서 시작하며 등록된 학년별로 전환할 수 있습니다.

분석 항목:
- 성별: 남 / 여
- 부모 신앙: 부모 모두 신앙 / 한 분 신앙 / 비신자 가정
- 다문화: 다문화 가정 / 일반 가정
- 타부서 형제자매: 있음 / 없음

비율의 분모는 항상 현재 보고 있는 전체 학생 수입니다. 부모 신앙·성별 값이 아직 정리되지 않은 학생은 회색 `미분류` 영역으로 표시하여 잘못된 비율을 만들지 않습니다.

각 범례를 누르면 해당 학생 목록이 열리고, 학생을 누르면 기존 학생 상세로 연결됩니다.

청년교사용에서는 `학생 분석` 버튼과 민감 비교정보 필터를 표시하지 않습니다.

## 2. 학생 비교정보 입력

기존 학생 데이터 구조를 갈아엎지 않고 기존 필드와 최소 새 필드만 사용합니다.

- 성별: 기존 `남 / 여` 값 사용
- 담당교사: 자유입력이 아니라 현재 교사명단 선택
- 부모 신앙: `부모 모두 신앙 / 한 분 신앙 / 비신자 가정` 중 하나 선택
- 다문화 가정: 체크박스
- 우리 교회 다른 부서에 형제·자매 있음: 체크박스
- 형제·자매 상세: `이름 · 관계 · 부서` 자유 메모

기존의 단순 `신자` 값은 임의로 해석하지 않고 `신앙 가정(기존) · 확인 필요`로 보존합니다.

## 3. 학생 필터

학년·팀은 각 화면의 `보기`가 담당하고 학생 필터에서는 추가 관리조건만 선택합니다.

임원·양육교사용:
- 담당교사
- 부모 신앙
- 다문화
- 타부서 형제자매
- 성별
- 장기 미출석 / 최근 출석

청년교사용:
- 담당교사
- 성별
- 출석 상태

이전 임원용 민감 필터 값이 메모리에 남아 있어도 청년교사용 목록을 몰래 제한하지 않도록 실제 필터 조건에서도 초기화합니다.

## 4. Excel / 데이터팩 연결

학생 Excel 내보내기에 다음 열을 추가했습니다.

- 담당교사
- 부모신앙
- 다문화
- 타부서형제자매
- 타부서형제자매비고

학생 Excel 가져오기도 위 항목의 별칭을 읽어 기존 학생 ID와 기록을 보존하면서 병합합니다.

임원·양육교사용 데이터팩은 비교정보를 포함합니다.
청년교사용 데이터팩은 부모 신앙·다문화·타부서 형제자매·상세비고를 포함하지 않습니다.
청년교사용 `현재 명단 교체`를 선택하면 활성 학생의 민감 비교정보도 최소정보 기준으로 정리합니다.

데이터팩의 기존 `업데이트 / 현재 명단 교체` 선택과 과거 출석·달란트 보존 원칙은 유지합니다.

## 5. 기존 기능 회귀 방지 확인

이번 기능과 직접 관련 없는 기존 구조는 재작성하지 않았습니다. 다음 핵심 경로를 다시 검사했습니다.

- 달란트: 선택 학생만 지급, 미선택 지급 금지, 차감 후 +모드 복귀, ×2 1회 적용
- 학생 출석: 화면만 열어 기록 생성 금지, 실제 체크 시 기록 생성, 마지막 체크 해제 시 빈 기록 정리
- 교사 출석: 화면만 열어 기록 생성 금지, 실제 체크 시 생성, 마지막 체크 해제 시 정리
- 출석 정렬: 가나다/학년, 체크 중 순서 고정, 장기 미출석 하단
- 출석 기록: 기본 접힘, `보기 · 수정 / 삭제` 유지
- 담당 학년: 기본 시작 범위일 뿐 다른 학년 접근 제한 없음
- 학생 분석/필터: 임원용 상세정보와 청년용 개인정보 제한 분리
- 데이터팩 업데이트: 파일에 없는 기존 활성 학생 유지
- 데이터팩 명단 교체: 파일에 없는 학생은 비활성화하되 과거 기록 보존
- 학생 Excel: 새 비교정보 열 포함

## 7. GitHub 반영

`v1.5.3.20-final-complete` 대비 실제 변경 파일만 교체합니다. `index.html`과 `sw.js`도 반드시 함께 반영해야 휴대폰 PWA가 새 코드를 받습니다.

이번 버전에서도 관리그룹 전용 독립 출석 같은 별도 다음 단계 기능은 새로 만들지 않았습니다. 기존 학생·교사·출석·달란트·기록·Excel·데이터팩 구조를 보존하는 것이 우선입니다.
