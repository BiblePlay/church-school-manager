# 교회학교 출석 · 달란트 PWA v1.5.3.20-final-complete

기준 버전: `v1.5.3.19-final-stable`

이 버전은 새 기능을 크게 늘린 버전이 아니라, 기존 기능을 보존하면서 여러 세대의 패치가 서로 덮어쓰던 부분을 실제 로드 순서 기준으로 점검하고 정리한 **코드 기준 최종 통합 안정화본**입니다.

## 최종 고정 동작

### 학년 · 보기
- 전체 관리자: 기본 범위는 `전체`. 담당 학년 선택을 요구하지 않습니다.
- 담당 선생님: 설정한 담당 학년이 달란트·출석·기록·학생명부의 기본 시작 학년입니다.
- 담당 학년은 접근 제한이 아닙니다. 등록된 다른 학년과 실제 등록된 팀도 `보기`에서 선택할 수 있습니다.
- 기본 `팀` 버튼은 만들지 않습니다. 사용자가 실제 만든 팀만 표시합니다.

### 출석
- 화면을 열거나 날짜만 바꿔서는 기록을 만들지 않습니다.
- 학생은 실제 출석/지각/새친구 체크가 있을 때만 기록됩니다.
- 교사는 실제 출석/지각 또는 사유 입력이 있을 때만 기록됩니다.
- 같은 날짜/같은 세션은 새 기록이 아니라 기존 기록을 수정합니다.
- 마지막 실제 체크를 모두 해제하면 빈 출석 기록은 제거하되, 같은 날짜의 달란트 기록은 보존합니다.
- 정렬은 `가나다 / 학년`이며, 체크 도중 학생 순서가 움직이지 않습니다.
- 장기 미출석자는 목록 맨 아래에 유지되고 일반 출석 분모에서 별도로 처리됩니다.

### 출석 기록
- 메인 화면에 기록을 무한히 펼치지 않고 `출석 기록 보기` 안에서 관리합니다.
- 날짜별 `보기 · 수정 / 삭제`를 지원합니다.
- 연도·월 필터와 월별 묶음을 지원합니다.
- 현재 범위 기준 Excel/TXT 내보내기를 지원합니다.
- 통합 `출석 Excel`은 학생 출석과 교사 출석을 각각 시트로 나눕니다.

### 달란트
- 선택 학생에게만 지급합니다. 미선택 상태에서 전원 지급하지 않습니다.
- `+10 / +20 / +50 / +100`, 차감 모드, 1회 차감 후 자동 +모드 복귀, `×2`, 리셋, 공유 구조를 유지합니다.

### 설정 · 데이터 흐름
설정 화면은 기능을 합쳐 데이터를 바꾸지 않고, 목적별 입구를 구분했습니다.

- **명단 가져오기**: 학생/통합 Excel, 교사 Excel
- **데이터팩**: 임원·양육교사용 / 청년교사용 내보내기 및 가져오기
- **출석 기록 이동**: 받은 기록 반영, 출석 기록 파일 내보내기/가져오기
- **Excel 내보내기**: 출석 Excel, 달란트 Excel 등 사람이 보는 보고서
- **백업 · 복구**: 현재 앱 전체 상태를 보관/복원
- **고급 데이터 관리**: 초기화·이전 상태 복원 같은 위험 작업을 별도 영역으로 격리

`등록 학년 정리`와 `등록 팀 관리`는 실제 데이터 구조를 관리하는 기능이고, `내 담당 학년/팀`은 기본 시작 범위를 정하는 기능으로 구분합니다.

### 데이터팩 가져오기
임원·양육교사용과 청년교사용 데이터팩 모두 다음 방식을 선택할 수 있습니다.

1. **기존 데이터 업데이트**
   - 같은 ID는 기존 항목에 병합
   - 새 항목 추가
   - 파일에 없는 기존 활성 명단은 유지
   - 기존 출석·달란트·과거 기록 유지

2. **현재 명단 교체**
   - 파일 기준으로 현재 활성 명단을 정리
   - 파일에 없는 기존 학생/교사는 삭제하지 않고 비활성 처리
   - 기존 ID와 출석·달란트·과거 기록 보존
   - 청년교사용 교체 시 학생 민감 상세정보를 활성 데이터에서 제거하고 최소정보 접근 기준을 적용

임원·양육교사용 데이터팩은 학생 상세정보와 심방/연락 기록을 포함할 수 있으며, 청년교사용 데이터팩은 학생 상세 개인정보와 심방 기록을 제외합니다. 출석 기록은 내보낼 때 선택할 수 있습니다.
