# v1.5.3.25-final-filter-clean

기준 버전: `v1.5.3.24-final-mobile-release`

이번 작업은 **학생 필터에서 `담당교사` 항목만 제거**한 마지막 정리입니다.

## 이번 수정

- 학생 필터 모달에서 `담당교사` 선택 항목 제거
- 이전 버전에서 담당교사 필터가 선택된 채 남아 있어도 학생 목록을 숨기지 않도록 해당 조건을 항상 해제
- 필터 적용 개수에서도 담당교사 조건 제외

## 그대로 유지

- 학생 상세의 담당교사 최대 2명
- 학년·팀 교사 공통 지정
- Excel/데이터팩의 담당교사 정보
- 학생 분석, 부모 신앙, 다문화, 타부서 형제자매, 성별, 출석 상태 필터
- 학년·팀은 각 화면의 `보기`에서 선택
- 달란트, 학생/교사 출석, 출석 기록, 학생별 출석 흐름, 명부, Excel, 데이터팩, 백업/복원, 자료 보관함

## v1.5.3.24 내용 보존

# v1.5.3.24-final-mobile-release

기준 버전: `v1.5.3.23-homeroom-common`

이번 작업은 기존 안정 기능을 유지한 채 마지막 모바일 마감 범위만 수정합니다.

## 이번 수정

1. 학생 분석 도넛 차트
- 차트 조각 위에 `명수 + 퍼센트`를 직접 표시합니다.
- 기존 범례·학생 목록 연결은 그대로 유지합니다.

2. 학년 · 팀 담당교사 공통 지정
- 설정 첫 화면에는 긴 교사 체크 목록을 펼치지 않습니다.
- `학년 · 팀 교사 지정` 버튼을 눌렀을 때만 별도 화면이 열립니다.
- 학년별/팀별 최대 2명까지 다중선택할 수 있습니다.
- `저장하고 닫기` 후 설정 화면으로 돌아옵니다.
- 학년 공통 담임은 해당 학년 학생의 기존 `담당교사` 필드에 호환 저장합니다.
- 팀 담당교사 설정은 팀 운영정보로 보존하며 학생의 학년 담임을 덮어쓰지 않습니다.

3. JSON/TXT 기록 파일 보관
- 앱이 만든 JSON/TXT는 `자료 보관함`에도 자동 저장합니다.
- 자료 보관함에서 JSON은 다시 불러오기, JSON/TXT는 다시 저장·삭제할 수 있습니다.
- 폴더 직접 지정이 가능한 기기에서는 처음 한 번 선택한 위치 아래 `교회학교 출석달란트 자료` 폴더를 사용합니다.
- 폴더 직접 지정이 제한되는 기기에서도 앱 자료 보관함에서 파일을 다시 찾을 수 있습니다.
- 전체 백업도 같은 보관 흐름을 사용합니다.
- Excel 내보내기 방식은 기존 기능을 유지합니다.

4. 모바일 최종 점검
- 360 / 390 / 430px 폭에서 달란트·출석·기록·학생·설정 화면의 가로 밀림을 점검했습니다.
- 학년·팀 교사 지정 화면, 학생 분석, 자료 보관함도 같은 폭에서 점검했습니다.

## 보존한 핵심 기능

- 달란트: 선택 학생만 지급, 미선택 지급 금지, 차감 후 +모드 복귀, ×2, 리셋, 공유
- 학생/교사 출석: 실제 체크한 날만 기록, 같은 날짜 수정, 빈 기록 자동 생성 금지
- 출석 체크 중 학생 순서 고정, 가나다/학년 정렬, 장기 미출석자 아래 배치
- 출석 기록: 접힌 기록 목록, 보기·수정·삭제, 월/연도, Excel/TXT
- 학생별 출석 흐름 높은순/낮은순
- 학생·교사 명부, Excel 가져오기, 데이터팩 업데이트/명단 교체, 전체 백업/복원
- 청년교사용 민감정보 제한
