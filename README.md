# 교회학교 출석 · 달란트 v1.5.1.4

이번 버전은 기존 UI와 주요 기능을 유지한 채 학생 Excel 연락처 병합과 연락처 편집만 보강한 테스트/마감 후보입니다.

## 이번 수정
- 같은 학생이면 기존 Student ID와 출석·달란트·심방 기록을 유지하며 상세정보 업데이트
- Excel 빈칸은 기존 정보를 지우지 않음
- 부/모/고모/이모/할머니/외할머니 등 관계가 붙은 전화번호를 관계 정보와 함께 보존
- 학생 상세에서 가족·친척 연락처를 이름 / 관계 / 전화번호로 수정
- 연락처 추가 / 삭제 / 위아래 순서 변경
- 저장된 연락처는 학생 명부·출석 화면의 빠른 연락창에서 전화/문자에 사용
- 임원·양육교사용 / 청년교사용 데이터팩 구조 유지

## 테스트 순서
1. 현재 복원 데이터에서 학생 Excel을 `기존 명단 업데이트`로 분석합니다.
2. 미리보기에서 `정보 업데이트`가 잡히는지 확인합니다.
3. 적용 후 학생 한 명을 열어 부/모/친척 관계와 전화번호를 확인합니다.
4. 필요하면 학생 상세에서 관계·이름·번호·순서를 수정하고 저장합니다.
5. 임원·양육교사용 데이터팩을 내보내 다른 브라우저에 넣어 상세 연락처가 동일한지 확인합니다.
6. 청년교사용 데이터팩을 넣어 학생 상세 개인정보는 제외되고 최소 학생명단+교사 연락처만 들어가는지 확인합니다.
