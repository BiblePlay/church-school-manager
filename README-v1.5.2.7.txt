교회학교 출석 · 달란트 v1.5.2.7

이번 수정 범위
1. Android/Galaxy 설치 안내
   - PWA 설치 이벤트가 준비되면 앱의 설치 버튼이 실제 설치창을 호출합니다.
   - 설치창을 직접 호출할 수 없는 브라우저에서는 아무 반응 없이 끝나지 않고,
     현재 브라우저에서 따라 할 수 있는 설치 경로를 화면 안에 표시합니다.
   - 인앱 브라우저로 판단되면 '다른 브라우저로 열기 → Chrome/삼성 인터넷 → 앱 설치/홈 화면에 추가'를 안내합니다.
2. 설치 안내와 데이터 가져오기 안내가 동시에 겹치지 않도록 순서를 정리했습니다.
3. 설정 → 화면 모드 추가
   - 시스템 / 밝게 / 어둡게
   - 선택은 이 앱에만 저장되며 휴대폰 전체 화면 설정은 변경하지 않습니다.
   - 어두운 모드는 차콜 배경 + 밝은 글자 + 기존 노란 포인트를 유지합니다.
4. 기존 v1.5.2.6의 학생정보, 출석, 달란트, 차감 자동복귀, 공유, Excel, 교사, 데이터팩 로직은 수정하지 않았습니다.
5. TalentApp_Local.command 영문 파일명 유지.
