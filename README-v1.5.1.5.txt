v1.5.1.5 FINAL VIEW PATCH

기준: v1.5.1.4-contact-data-final 그대로 유지.

이번 수정은 학생 상세의 표시 기능 1가지만 추가했습니다.
- Excel/앱에 이미 저장된 학교, 주소, 형제관계, 부모 신앙, 다문화, 기타 분류, 메모 등을
  입력칸을 펼치지 않아도 학생 상세 상단의 "등록된 학생 정보"에서 바로 확인할 수 있습니다.
- 값이 없는 항목은 표시하지 않아 화면이 불필요하게 길어지지 않습니다.
- 기존 입력/수정 영역은 그대로 남아 있습니다.

수정하지 않은 것:
출석, 달란트, 공유, 교사, Excel 병합, 데이터팩 2종, 연락처 편집, 설치/PWA, 전체 UI 구조.
